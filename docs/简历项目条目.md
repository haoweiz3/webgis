## 长江武汉段三维时空数据可视化平台（个人项目 · 2026）

**技术栈**：Vue3 · Vite · Cesium 1.97 · ECharts · Pinia · JavaScript · Sass

一句话：面向三维 GIS 平台研发岗位，独立设计并实现的三维时空数据可视化平台，以长江武汉段为研究区，用时间轴驱动水位与监测数据的动态表达，并提供量算、剖面、淹没三类空间分析工具。

**核心工作**

1. **搭建可插拔的三维平台架构**：设计并实现统一的模块契约（`init(ctx)` / `destroy()`）与模块注册中心，11 个功能模块（底图、地形、水域岸线、桥梁、路网、站点、时间轴、状态读数、量算、剖面、淹没）均由平台统一挂载与销毁；通过事件总线与 Pinia 分离"一次性通知"和"共享状态"，实现功能可开关、可复用、无残留。
2. **实现时空数据可视化闭环**：设计 24 个监测站点（水位站/水质站/雨量站）的专题表达方案，用 `CallbackProperty` 将时间轴状态逐帧映射到站点颜色、尺寸与标注；点击站点联动 ECharts 水位过程线与当前时刻游标，图表游标与场景双向同步。
3. **实现空间分析工具链**：距离量算采用椭球测地线、面积量算自实现球面多边形公式（不依赖第三方空间库）；剖面分析通过 `sampleTerrainMostDetailed` 沿线采样地形高程并绘制剖面曲线；淹没分析按"滩地单元高程 + 水位判定 + 面积累加"实现，面积与库区水位实时联动。
4. **处理高程基准问题**：将水位、滩地高程、警戒水位统一到吴淞高程参与分析，仅在三维渲染时按固定偏移量换算为场景高程，避免混用基准导致淹没判定错误，并在文档中说明生产环境需用基准转换模型精算。
5. **构建演示数据集**：编写数据生成脚本，输出水域面、岸线、滩地单元、桥梁、主干道、站点与时序数据；模拟 96 小时降雨—洪水过程（雨峰 → 涨水 → 超警戒洪峰 → 退水），流量按水位—流量关系曲线反算，使演示数据具备水文内在逻辑。

**项目亮点（面试可讲）**

- 平台化而非页面化：模块契约 + 注册中心 + 事件总线 + 状态管理，能回答"20 个功能怎么组织、怎么保证互不干扰、怎么避免内存泄漏"。
- 空间数据组织：影像/地形/矢量/时序多源数据的加载、坐标系与高程基准处理、图层分组管理。
- 场景与图表联动：三维场景、ECharts 图表、HUD 面板三者的状态同步设计。

**关键词**：Cesium、三维 GIS、时空数据可视化、空间分析、图层管理、坐标与高程基准、Vue3 组件化、ECharts、Pinia、Vite
